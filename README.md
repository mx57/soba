# 🐾 Десктопный Котик (Desktop Pet Cat) ⚡

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![UI: PySide6](https://img.shields.io/badge/UI-PySide6-green.svg)](https://pypi.org/project/PySide6/)

Интерактивный векторный питомец для вашего рабочего стола, который живет своей жизнью, пока вы работаете. Теперь еще умнее, быстрее и преданнее!

---

## ✨ Что нового: Система привязанности и Оптимизация

Мы добавили глубины в ваши отношения с питомцем и сделали приложение максимально легким для системы.

### ❤️ Система привязанности (Affection System)
Ваш котик теперь запоминает вашу заботу!
- **Копите очки**: Взаимодействуйте с питомцем, гладьте его или просто работайте рядом.
- **Уровни дружбы**: Каждые 100 очков повышают ваш уровень. Котик поблагодарит вас особым уведомлением и радостным мяуканьем.
- **Память**: Весь прогресс сохраняется в локальной базе данных SQLite.

### 🧠 Умный Watchdog
Больше никаких "зависших" анимаций!
- Котик автоматически понимает, когда вы отошли от компьютера или перестали активно двигать мышкой, и плавно возвращается в режим **Idle** через 2 секунды тишины.

### ⚡ Bolt-Оптимизации (Performance)
- **SVG-революция**: Бесконечное масштабирование без потери четкости.
- **Eye-Tracking 2.0**: Прямое использование системных хуков для слежения глазами без лишней нагрузки на CPU.
- **Smart Batching**: Запись в базу данных происходит пачками, экономя ресурс вашего диска.

## 🛠 Ключевые Механики

- **🖱 Mochi Drag**: Тяните котика за лапки! Он эластично растягивается, а если его встряхнуть — начнет дрожать.
- **🎯 Mouse Hunt**: Если вы слишком быстро двигаете мышкой, инстинкты возьмут верх и котик бросится в погоню.
- **🍎 Productivity Boost**: Встроенный Pomodoro-таймер и напоминания о разминке.
- **👻 Peek Mode**: Котик может спрятаться за край экрана, выглядывая и не мешая важным делам.

## ⚙️ Установка и запуск

1. **Требования**: Python 3.10 или выше.
2. **Установка зависимостей**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Запуск**:
   ```bash
   python main.py
   ```
